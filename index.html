Working on · CSE 585 course project

Speculative KV-cache quantization for agentic serving

An LLM's KV cache grows linearly with context, which gets painful in long, multi-turn agent sessions. Today's options either evict tokens for good or quantize everything uniformly and lose nuance. Our approach: when GPU memory pressure crosses a threshold, a cheap draft model runs several lookahead rollouts in parallel. Tokens those rollouts agree are important stay in high precision, and the rest of the context gets compressed to low-bit.
